## Pipeline Run 失败后资源清理

```shell
kubectl delete pod -l tekton.dev/pipelineRun=<pipeline-run-name> -n <namespace>
kubectl delete pipelinerun <pipeline-run-name> -n <namespace>
kubectl delete taskrun -l tekton.dev/pipelineRun=<pipeline-run-name> -n <namespace>
```
