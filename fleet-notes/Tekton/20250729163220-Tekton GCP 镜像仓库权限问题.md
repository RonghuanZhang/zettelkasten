# 尝试二：使用 Secret 文件

要在 **Tekton** 中使用 **Docker Registry 的 GCP 服务账号认证（即 `docker login` 凭证）**，你需要把认证信息以 **Kubernetes Secret（类型为 `dockerconfigjson`）** 存储起来，然后 **在 Task 中引用这个 Secret 作为 ImagePullSecret 或 Workspace**。

---

## ✅ 步骤：通过 Tekton 使用 GCP SA 认证 Artifact Registry

### 🔹 1. 创建 Docker 登录 Secret（推荐方式）

```bash
cat hive-451307-956faf567709.json | docker login -u _json_key --password-stdin https://us-central1-docker.pkg.dev

docker login -u _json_key -p "$(cat hive-451307-956faf567709.json)" https://us-central1-docker.pkg.dev

```

然后导出 Docker 的认证配置：

```bash
cat ~/.docker/config.json
```

在 MacOS 下根本无法取到该值。

创建 Secret：

```bash
kubectl create secret generic regcred \
  --type=kubernetes.io/dockerconfigjson \
  --from-file=.dockerconfigjson=<path-to-your-config.json> \
  -n <your-namespace>

```

例如：

```bash
kubectl create secret generic regcred \
  --type=kubernetes.io/dockerconfigjson \
  --from-file=.dockerconfigjson=./config.json \
  -n my-tekton
```

---

### 🔹 2. 在 `PipelineRun` 中引用这个 Secret

Tekton 中有两种主要方式引用 Secret：

#### ✅ （A）用于拉取镜像（ImagePullSecret）

```yaml
apiVersion: tekton.dev/v1
kind: PipelineRun
metadata:
  name: example-run
spec:
  serviceAccountName: my-service-account
  ...
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: my-service-account
  namespace: my-tekton
secrets:
  - name: regcred
imagePullSecrets:
  - name: regcred
```

> 确保你的 Pod 使用的是这个 ServiceAccount，Tekton 会自动使用该 `imagePullSecret` 拉取镜像。

---

#### ✅（B）作为 Workspace（如果你需要在 Pipeline 中使用 `config.json` 进行操作）

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: regcred
  namespace: my-tekton
type: Opaque
stringData:
  config.json: |
    {
      "auths": {
        "LOCATION-docker.pkg.dev": {
          "auth": "base64(_json_key:xxxxx)"
        }
      }
    }
```

然后在 Task 中引用：

```yaml
workspaces:
  - name: docker-config
    secret:
      secretName: regcred
      items:
        - key: config.json
          path: config.json
```

并挂载到路径 `/kaniko/.docker/config.json`（如用于 `kaniko`）或其他需要认证的工具。

---

## 🔎 总结

| 用途                 | Secret 类型                        | 方式               |
| ------------------ | -------------------------------- | ---------------- |
| 镜像拉取认证（docker.pkg） | `kubernetes.io/dockerconfigjson` | imagePullSecrets |
| 工作区中使用（如 Task 中操作） | `Opaque` + `stringData`          | Workspace        |

* Registry 地址（例如 `asia-southeast1-docker.pkg.dev`）

# 最终解决的方案

```shell

# GSA JSON 文件做成config.json
cat <<EOF > config.json
{
  "auths": {
    "https://us-central1-docker.pkg.dev": {
      "username": "_json_key",
      "password": $(cat hive-451307-b93b90c1eaa0.json | jq -Rs .)
    }
  }
}
EOF

# 创建一个Secret
kubectl create secret generic docker-config-secret \
  --from-file=config.json=./config.json \
  -n tekton-workspace

# 测试
DOCKER_CONFIG=$(pwd) docker pull us-central1-docker.pkg.dev/hive-451307/hive/ronghuanz/hive-func-test-01:1.0.0
```
