## Fluent Bit 转发日志到 Loki


## Loki API


```shell

# 查看所有的标签
curl -s "http://127.0.0.1:3100/loki/api/v1/labels" \
     -H 'X-Scope-OrgID: ronghzhang11' \
  | jq .

# 查看标签的值
curl -s "http://127.0.0.1:3100/loki/api/v1/label/namespace/values" \
     -H 'X-Scope-OrgID: ronghzhang11' \
  | jq .
  
# 查看日志内容
curl "http://127.0.0.1:3100/loki/api/v1/query_range" --data-urlencode 'query={namespace="tenant_id"}' -H 'X-Scope-OrgId: ronghzhang11'

```
