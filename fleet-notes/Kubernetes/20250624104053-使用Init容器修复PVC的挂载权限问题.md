```YAML
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: hive-application
  namespace: hive
  labels:
    app: hive-application
spec:
  serviceName: hive-application
  replicas: 1
  selector:
    matchLabels:
      app: hive-application
  template:
    metadata:
      labels:
        app: hive-application
    spec:
      securityContext:
        runAsGroup: 1000
        runAsUser: 1000
        fsGroup: 1000
      initContainers:
        - name: fix-permissions
          image: busybox
          command: [ "sh", "-c", "chown -R 1000:1000 /app/jvm-logs /app/dumps" ]
          securityContext:
            runAsUser: 0
          volumeMounts:
            - name: logs
              mountPath: /app/jvm-logs
            - name: dumps
              mountPath: /app/dumps
```

需要保证跟 Dockerfile 中的 Run 用户和组一致。
