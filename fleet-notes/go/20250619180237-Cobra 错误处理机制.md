在使用 [Cobra](https://github.com/spf13/cobra) 开发 CLI 工具时，错误处理有以下几种常见的方式，你可以根据具体场景选择合适的处理策略：

---

## ✅ 常见的 Cobra 错误处理方式

### 1. **统一处理 `Execute()` 返回的错误**

这是 Cobra 推荐的方式：

```go
func main() {
	if err := rootCmd.Execute(); err != nil {
		fmt.Fprintf(os.Stderr, "Error: %v\n", err)
		os.Exit(1) // 非零表示出错
	}
}
```

> 优点：所有命令的错误会统一由 `Execute()` 返回，集中处理。

---

### 2. **子命令中返回错误**

在每个子命令的 `RunE` 函数中返回错误：

```go
var helloCmd = &cobra.Command{
	Use:   "hello",
	Short: "Say hello",
	RunE: func(cmd *cobra.Command, args []string) error {
		if len(args) == 0 {
			return errors.New("name is required")
		}
		fmt.Printf("Hello, %s!\n", args[0])
		return nil
	},
}
```

> `RunE` 代表 `Run with error`，推荐使用这个而不是 `Run`，这样错误可以回传到 `Execute()`。

---

### 3. **自定义错误信息格式**

如果你想统一处理格式或加上颜色、日志，可以这样处理：

```go
func main() {
	if err := rootCmd.Execute(); err != nil {
		log.Fatalf("\033[31m✖ %v\033[0m\n", err) // 红色输出
	}
}
```

---

### 4. **使用 `SilenceUsage` 和 `SilenceErrors` 控制输出**

避免 Cobra 在错误发生时自动打印 usage 和错误堆栈：

```go
var rootCmd = &cobra.Command{
	Use: "app",
	SilenceUsage:  true, // 错误时不显示 usage
	SilenceErrors: true, // 错误时不自动打印 error，自己处理
}
```

> 推荐开启这两个选项，让你自己控制错误输出。

---

### 5. **打印帮助信息**

在参数不全或者特定错误时，可以手动触发帮助信息显示：

```go
if len(args) == 0 {
	_ = cmd.Help() // 打印帮助信息
	return errors.New("you must provide an argument")
}
```

---

## 🧪 示例组合

```go
package main

import (
	"errors"
	"fmt"
	"os"

	"github.com/spf13/cobra"
)

var rootCmd = &cobra.Command{
	Use:           "mycli",
	SilenceUsage:  true,
	SilenceErrors: true,
}

var helloCmd = &cobra.Command{
	Use:   "hello [name]",
	Short: "Say hello",
	Args:  cobra.ExactArgs(1),
	RunE: func(cmd *cobra.Command, args []string) error {
		name := args[0]
		if name == "" {
			return errors.New("name cannot be empty")
		}
		fmt.Printf("Hello, %s!\n", name)
		return nil
	},
}

func main() {
	rootCmd.AddCommand(helloCmd)

	if err := rootCmd.Execute(); err != nil {
		fmt.Fprintf(os.Stderr, "Error: %v\n", err)
		os.Exit(1)
	}
}
```

---

如需支持更加复杂的错误处理（如 logging、stack trace、错误分类），可以考虑引入：

- `pkg/errors`
    
- `github.com/hashicorp/go-multierror`
    
- `zap` 或 `logrus` 日志库
