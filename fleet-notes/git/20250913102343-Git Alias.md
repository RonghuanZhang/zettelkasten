可以，用 **Git alias** 做个“一键：按路径 add + commit(带时间) + push”的命令。下面给你现成的别名，默认把时区设为新加坡（Asia/Singapore），消息格式就是你之前用的 `memos back up <时间>`。

# 一键别名（bash / zsh / Git Bash 通用）

把这个写入你的 `~/.gitconfig`（推荐），或直接运行下面的 `git config` 一行命令。

**写入 `~/.gitconfig` 的方式：**

```ini
[alias]
  bakp = !f() { \
    ts=$(TZ=Asia/Singapore date '+%Y-%m-%d %H:%M:%S %z'); \
    msg=${1:-"memos back up $ts"}; \
    shift || true; \
    # 支持用 -- 分隔：前面是可选消息，后面是路径
    if [ "${1:-}" = "--" ]; then shift; fi; \
    if [ $# -lt 1 ]; then \
      echo "用法：git bakp [可选: \"commit msg\"] -- <path1> [path2 ...]" >&2; \
      return 1; \
    fi; \
    git add -A -- "$@"; \
    git commit -m "$msg" --only -- "$@"; \
    git push -u origin HEAD; \
  }; f
```

**或用一行命令直接写入（等价于上面那段）：**

```bash
git config --global alias.bakp '!f(){ ts=$(TZ=Asia/Singapore date "+%Y-%m-%d %H:%M:%S %z"); msg=${1:-"memos back up $ts"}; shift || true; if [ "${1:-}" = "--" ]; then shift; fi; if [ $# -lt 1 ]; then echo "用法：git bakp [\"msg\"] -- <path...>" >&2; return 1; fi; git add -A -- "$@"; git commit -m "$msg" --only -- "$@"; git push -u origin HEAD; }; f'
```

## 怎么用

```bash
# 1) 仅给路径（自动带时间的消息）
git bakp -- notes/ scripts/README.md

# 2) 自定义消息 + 路径（建议用 -- 分隔，避免歧义）
git bakp "fix export bug" -- src/exporter.py

# 3) 多个路径
git bakp -- src/ docs/**.md
```

说明：

* `git add -A -- <paths>` 会把这些路径下的新增/修改/删除全部纳入暂存；
* `git commit --only -- <paths>` 确保**只**提交这些路径（不会夹带其他已暂存改动）；
* `git push -u origin HEAD` 第一次会自动建立 upstream，之后直接 `git bakp …` 就行。

# Windows 走 PowerShell 的版本（可选）

如果你更常用 PowerShell，可以把下面的函数加到 `$PROFILE`：

```powershell
function git-bakp {
  param(
    [string]$Message = ("memos back up " + (Get-Date -Format 'yyyy-MM-dd HH:mm:ss zzz')),
    [Parameter(Mandatory=$true, ValueFromRemainingArguments=$true)]
    [string[]]$Paths
  )
  git add -A -- $Paths
  git commit -m $Message --only -- $Paths
  git push -u origin HEAD
}
Set-Alias bakp git-bakp
```

用法同上：

```powershell
bakp -- notes\  # 自动时间
bakp "weekly backup" -- notes\README.md
```
