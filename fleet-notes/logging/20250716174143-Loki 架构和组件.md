## Loki 组件

### ⚙️ **核心 Loki 组件职责**

| 组件                  | 类型          | 作用                                                           | 备注                    |
| ------------------- | ----------- | ------------------------------------------------------------ | --------------------- |
| **distributor**     | Deployment  | 接收推送来的日志（Promtail, Fluentbit 等），验证、分片，并转发给 ingester          | 可水平扩展；无状态             |
| **ingester**        | StatefulSet | 接收 distributor 分发的日志流，写入 chunk，负责持久化到对象存储，并提供 recent logs 查询 | 保持在 ring 中注册；支持 WAL   |
| **querier**         | Deployment  | 查询节点，从 ingester (近实时) + 对象存储 (历史) 聚合结果返回                     | 主要执行查询请求              |
| **query-frontend**  | Deployment  | 查询前端，接收用户查询，拆分并优化查询，缓存查询结果                                   | 提高查询性能与缓存命中率          |
| **query-scheduler** | Deployment  | 将查询调度到 querier，优化分发                                          | 提升大查询稳定性，可选但推荐        |
| **compactor**       | StatefulSet | 压缩、合并 index blocks，减少查询次数和提升性能                               | 使用 BoltDB Shipper 时必需 |
| **index-gateway**   | StatefulSet | 加速 index blocks 查询，减少对象存储访问次数                                | Cortex/Loki 优化组件      |
| **ruler**           | StatefulSet | 执行基于日志查询的 Alerting rules                                     | 这里显示 0/0，可能当前未启用      |
| **gateway**         | Deployment  | 提供统一入口 (nginx 反向代理)，暴露 Loki API 和 UI                         | 通常绑定 Service, Ingress |

---

### 🗃 **缓存与存储相关**

| 组件                | 类型          | 作用                                   |
| ----------------- | ----------- | ------------------------------------ |
| **chunks-cache**  | StatefulSet | 存放 chunk cache，减少对对象存储频繁请求           |
| **results-cache** | StatefulSet | 缓存查询结果，提高重复查询响应速度                    |
| **minio**         | StatefulSet | 本地对象存储 S3 兼容，用作 chunk 和 index 的持久化后端 |

---

### 🔎 **各组件交互简述**

```
Promtail → Distributor → Ingester → (存储到 MinIO)

查询:
Query Frontend → Query Scheduler → Querier → (Ingester + MinIO)

Compactor 定期合并 index，提高查询效率。
Index Gateway 缓存 index blocks，减少对 MinIO 请求。

Ruler 定时执行查询表达式，结合 Alertmanager 实现告警。
```

---

### 💡 **你需要注意**

✅ Distributor、Querier、Query Frontend 可水平扩展无状态
✅ Ingester 通常使用 StatefulSet，需配置 replication factor >= 3
✅ MinIO 在生产可替换为 AWS S3, GCS 等托管存储
✅ 如果 `ruler` 为 0/0，确认 values.yaml 中是否启用规则引擎
