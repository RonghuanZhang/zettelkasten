## 讲一下最近参与过的项目，在项目中负责的具体工作是什么？
电商平台，跨境电商，进口和出口

进口：买手店 API 对接商品和订单
出口：供应链，卖美国，订单量没怎么增长

从 0 - 1 的项目，进口链路商家对接，跑任务拉商品，然后自动化匹配，匹配符合的商品，需要鉴别商品通过的商品才能卖

映射字段，比如欧码到过码，映射后匹配，匹配分，货号匹配，匹配到得物的商品可以卖

询价：同一个商品优先按价格最低，还有时效等规则
定价：货币汇率转换，热销涨价，数据来源于算法
出价：美国、俄罗斯、韩国，中心库存+出价
订单：采购单，用户下单直接去商机下单，监听用户成功支付的消息，确认库存，推订单，创建成功

对接商家多少家？500 家+
商品数量：8000 w

8000 w 数据怎么存的？MySQL 存，查询全部走 ES。
数据一致性怎么保证的？Canal 监听 binlog

## 缓存系统设计

```java
public interface Cache {
    String put(String key, String value);
    String get(String key);
}
```

设计一个缓存系统

* 用 HashMap 放
* Put 后通知其他机器
* 重启后数据丢失了怎么办？
	* 持久化
		* 怎么存？
			* 类似AOF 写日志
			* 类似RDB 写快照，序列化
* 如何设置有效期？
	* 参考 Guava 整体设置个 Key
	* 参考 Redis 每个 Key 都放一个时间戳
		* Get 到了判断是否过期
		* 异步现场扫描
			* 数据量大扫描时间久 CPU 长怎么办
* 内存淘汰
	* LRU
	* LRU 额外维护链表导致内存效率比较低怎么办？
* Redis 集群模式有了解吗？
	* 16384 个槽位分配
	* 客户端访问槽定位 A 服务器，但因为平衡槽
	* 一致性算法，Raft，了解了一下，投票，过半
		* 说到 Nacos，怎么理解 AP 和 CP 的？
			* CAP 理论，zk CP，数据要一致性
			* Nacos AP 和 CP 切换
