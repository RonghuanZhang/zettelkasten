# Tasks

```shell
使用Golang Cobra框架编写以下逻辑CLI。
1. Login 接口
URL: /apis/app/v1/tenants/login
Method: POST
请求：
{
  "name": "",
  "password": ""
}
响应：
{
	"success": true,
	"errCode": "",
	"errMessage": "",
	"data": {
		"id": "",
		"name": "",
		"token": "",
		"timeout": 0
	}
}
CLI 格式:
saha-cli login
提示用户输入用户名和密码
存储data到用户目录下，以供后续使用

2. 创建Serverless 接口
URL: /apis/app/v1/tenants/{tenantId}/services
Method: POST
请求：
{
  "name": "",
  "configuration": {
    "sourceType": "",
    "sourceUri": "",
    "port": 0,
    "envs": [
      {
        "name": "",
        "value": ""
      }
    ],
    "cpuRequired": "",
    "memoryRequired": "",
    "cpuLimit": "",
    "memoryLimit": "",
    "minScale": 0,
    "maxScale": 0
  }
}
响应:
{
	"success": true,
	"errCode": "",
	"errMessage": "",
	"data": {
		"id": "",
		"name": "",
		"tenantId": ""
	}
}
CLI 格式：
saha-cli service create service-name -e key1=value1 -e key2=value2 -p port
如有需要补充其他即可。

每个都是HTTP调用，且可以通过参数指定host，需要对返回的HTTP状态码做判断。
```
