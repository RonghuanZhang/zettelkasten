## For leader

Hi team,  
We’re excited to announce that the FaaS feature has been released in version 1.2.0! 🎉  
Now you can simply write your code, push it to your GitHub repository, and deploy it. An HTTP endpoint will then be provided for invoking your function.

We currently support functions written in Golang, Node.js, and Spring Boot.  
For more details, please refer to the Hive [README](https://github.com/SaharaaQuestLab/hive/releases/tag/v1.2.0-alpha). If you’d like to give it a try, feel free to reach out to @ronghuanz.

## For users

🚀 FaaS is live in Hive **v1.2.0**!

Supports **Golang, Node.js, Spring Boot**.
