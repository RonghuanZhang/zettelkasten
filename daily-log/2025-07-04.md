## Jira
### 🗂️ **Epic: Centralized Logging System**

**Goal:** Provide users with efficient log access, streaming, and filtering capabilities.

* **Task:** Design the logging architecture and choose backend (e.g. Loki, ELK, Cloud Logging).
* **Task:** Implement per-service log aggregation and filtering support.
* **Task:** Develop CLI command `hive log` to stream logs (support both service and revision scopes).
* **Task:** Implement live log tailing via CLI.
* **Task:** Plan for web dashboard integration in future versions.

---

### 🗂️ **Epic: Service Update & Revision Management**

**Goal:** Enhance service deployment flexibility with traffic management and revision control.

* **Task:** Design and implement traffic splitting between revisions.
* **Task:** Enable revision creation and management for services.
* **Task:** Update CLI commands to support traffic configuration and revision operations.

---

### 🗂️ **Epic: Function-as-a-Service (FaaS)**

**Goal:** Allow users to write and deploy functions seamlessly, starting with HTTP triggers.

* **Task:** Design FaaS execution model integrated with existing Hive architecture.
* **Task:** Implement support for writing and deploying functions locally.
* **Task:** Implement HTTP trigger support for functions.
* **Task:** Update CLI to support function lifecycle management commands.

---

### 🗂️ **Epic: Metrics & Monitoring**

**Goal:** Provide operational visibility and alerting to ensure service reliability.

* **Task:** Integrate Prometheus for metrics collection.
* **Task:** Integrate Grafana for visualization.
* **Task:** Build default dashboards covering CPU, memory, and request metrics.
* **Task:** Define and implement alerting rules for CPU, memory, and request error rates.

---

### 🗂️ **Epic: Accounting & Usage Reporting**

**Goal:** Enable visibility into platform and service usage for billing and optimization.

* **Task:** Track invocation counts per service.
* **Task:** Implement data aggregation logic for usage reporting.
* **Task:** Generate monthly, weekly, and daily usage reports per service and tenant.
* **Task:** Expose usage reports via CLI and API.

---

### 🗂️ **Epic: Promotion & User Onboarding**

**Goal:** Drive adoption by onboarding users, gathering feedback, and improving system stability.

* **Task:** Identify and invite initial users to onboard Hive.
* **Task:** Collect user requirements and feedback systematically.
* **Task:** Assist users in testing workflows and document discovered issues.
* **Task:** Triage and fix bugs identified during onboarding.
