# Tasks

Hi Team. It's exciting to introduce the Hive Platform, a serverless deployment solution, which is now ready for **internal testing**!

Key Features:
* **Serverless**: No need to provision or manage servers. You can deploy the service by image and get the endpoint immediately.
* **CLI**: Deploy your applications straight from the command line in seconds.
* **Multi‑Tenant Isolation**: Isolation based on Kubernetes namespace.

How to use?
1. Contact @ronghuanz if you want to have a try.
2. Download the [CLI](https://github.com/SaharaaQuestLab/hive/releases/tag/v1.0.0-alpha) .
3. Refer to the [demo](https://github.com/SaharaaQuestLab/hive/tree/v1.0.0-alpha?tab=readme-ov-file#about-the-project) or  [guide](https://github.com/SaharaaQuestLab/hive/tree/v1.0.0-alpha?tab=readme-ov-file#usage).

When not to use?
1. **Stateful application**
2. **Long-Running, Resource-Intensive Jobs**
3. **Low-Latency, Real-Time Systems**

Please refer to the [hive README](https://github.com/SaharaaQuestLab/hive/tree/dev) to get more info. Please contact @ronghuanz if you have any questions.
